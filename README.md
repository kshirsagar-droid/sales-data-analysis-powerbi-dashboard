# Sales Data Analysis & Power BI Dashboard

## 📊 Project Overview

This is an end-to-end Sales Data Analytics project developed using **CSV, SQL, Power BI, and DAX**.

The project focuses on analyzing sales, profit, discounts, orders, payment methods, product categories, countries, and store locations.

The final result is an interactive Power BI dashboard that provides business insights through KPIs, charts, trends, and filters.

---

## 🛠️ Tools & Technologies

- **CSV** – Source data
- **SQL** – Data import, querying, transformation and analysis
- **Power BI** – Data modeling and dashboard development
- **DAX** – Calculated measures and KPI calculations
- **Excel** – Used for viewing/working with the source data where required

---
